# Prüfungs-Dashboard

[Dashboard öffnen](https://sl3ndrr.github.io/pr-fungsdashboard/)

Das Dashboard zeigt Prüfungen, Wiederholungstermine und die Portfolio-Abgabe in einer Terminliste und auf einem Zeitstrahl an. Der Hell-/Dunkelmodus und der Abgabestatus werden im jeweiligen Browser gespeichert.

## Termine pflegen

Öffne `index.html` direkt im Browser für eine lokale Vorschau. Die Termindaten stehen am Anfang des JavaScript-Blocks in derselben Datei. Die [Hinweise für die Pflege](AGENTS.md) beschreiben die Datenfelder und die Prüfungen vor einer Veröffentlichung.

## Veröffentlichung

GitHub Pages veröffentlicht das Dashboard statisch aus `main`. Die Startseite ist `index.html`. Den Status einer Veröffentlichung findest du unter [GitHub Actions](https://github.com/sl3ndrr/pr-fungsdashboard/actions).
